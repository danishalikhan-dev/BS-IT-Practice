
# Student Marks Calculator

## About the Project
My first C++ project as a BS IT student.

This program calculates a student's total marks,
percentage, and pass/fail status for three subjects.

## Features
- Accepts the student's name
- Takes marks for three subjects
- Calculates total marks and percentage
- Displays pass or fail status
- Validates marks from 0 to 100

## Technology Used
- C++
- Variables and arithmetic operations
- Input and output
- Conditional statements
